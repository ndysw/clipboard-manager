# 🖱️ 剪贴板历史管理器

一个智能的Windows剪贴板历史管理工具，支持在输入框中通过右键快速访问和粘贴历史复制内容。

## 📖 开发历程

### 项目起源
这个项目源于一个实际需求：在日常工作中经常需要复制多个内容，但Windows系统只能记住最后一次复制的内容。每次需要粘贴之前复制的内容时，都需要重新去找原文并复制，非常不便。

### 开发迭代记录

#### 第一阶段：基础功能实现
**目标**：实现剪贴板监控和双击右键弹出历史菜单

- 使用 `pyperclip` 监控剪贴板变化
- 使用 `pynput` 监听全局鼠标事件
- 使用 `tkinter` 创建弹出菜单
- 实现双击右键检测（0.5秒内两次右键）
- 实现基本的粘贴功能

**遇到的问题**：粘贴功能不稳定，经常粘贴失败

#### 第二阶段：修复粘贴问题
**问题表现**：
- 首次粘贴成功，第二次开始失败
- 监控显示"已粘贴"，但实际内容没有粘贴到输入框
- 程序卡顿，响应缓慢

**解决方案**：
1. **焦点问题**：菜单弹出后焦点停留在菜单窗口，没有回到输入框
   - 改用 `Toplevel()` 替代独立的 `Tk()` 实例
   - 使用 Windows API 保存并恢复窗口句柄
   - 添加 `SetForegroundWindow()` 主动恢复焦点

2. **时序问题**：粘贴操作太快，系统来不及响应
   - 菜单关闭等待时间从 0.1秒增加到 0.3秒
   - 剪贴板更新等待时间设为 0.15秒
   - 粘贴操作各步骤间增加 0.05秒延迟

3. **线程冲突**：剪贴板监控与粘贴操作冲突
   - 添加 `is_pasting` 标志位
   - 粘贴时暂停剪贴板监控
   - 使用独立线程执行粘贴操作

4. **键盘模拟**：pynput 键盘模拟不够稳定
   - 改用 Windows API `keybd_event` 模拟 Ctrl+V
   - 更精确的按键时序控制

#### 第三阶段：智能识别优化
**问题表现**：选中文字后右键想复制，却弹出了粘贴菜单

**解决方案**：
1. **文字选中检测**：
   - 实现 `has_text_selection()` 方法
   - 模拟 Ctrl+C 检测剪贴板是否变化
   - 如有文字选中，不弹出粘贴菜单

2. **可编辑区域检测**：
   - 使用 Windows API 获取窗口类名
   - 维护常见可编辑控件类名列表
   - 基于窗口标题识别编辑器（VSCode等）

3. **触发逻辑优化**：
   - 从双击右键改为单击右键
   - 仅在可编辑区域触发
   - 有文字选中时不干扰正常复制

#### 第四阶段：UI 交互增强
**优化目标**：提升用户体验，让界面更友好

**实现内容**：
1. **鼠标悬停效果**：
   - 从 `ttk.Frame` 改为 `tk.Frame` 支持背景色
   - 悬停时浅蓝色背景（#AED6F1）
   - 悬停时黄色粗体字（#F39C12）
   - 流畅的进入/离开动画效果

2. **滚轮支持**：
   - 添加鼠标滚轮事件绑定
   - 菜单关闭时自动解绑，避免影响其他程序

#### 第五阶段：系统托盘集成
**目标**：让程序后台运行，不占用任务栏

**实现内容**：
1. **图标设计**：
   - 使用 PIL 生成专业图标
   - 256x256 蓝色渐变圆形背景
   - 白色剪贴板主体 + 绿色历史时钟
   - 导出多尺寸 ICO 文件（16/32/48/64/128/256）

2. **托盘功能**：
   - 使用 `pystray` 库
   - 托盘菜单：显示历史、清空历史、退出
   - 托盘图标显示程序名称
   - 点击托盘图标可快速打开历史

3. **优雅退出**：
   - 实现 `quit_app()` 统一退出
   - 停止所有线程
   - 保存历史记录
   - 清理托盘图标

#### 第六阶段：打包与分发
**目标**：创建独立可执行文件，便于在其他电脑使用

**实现内容**：
1. **PyInstaller 打包**：
   - 创建 `clipboard_manager.spec` 配置文件
   - 集成图标文件
   - 单文件模式，无控制台窗口
   - 编写 `build.bat` 自动化脚本

2. **便携版制作**：
   - 创建 `create_portable.bat` 脚本
   - 生成 `ClipboardManager_Portable` 文件夹
   - 包含使用说明、启动脚本、开机启动脚本

3. **版本控制**：
   - Git 仓库初始化
   - 创建 `.gitignore` 排除编译文件
   - 上传到 GitHub

### 技术难点总结

1. **Windows 窗口焦点管理**：
   - 理解 GetForegroundWindow/SetForegroundWindow 机制
   - 正确保存和恢复窗口句柄
   - 处理不同应用程序的焦点特性

2. **多线程同步**：
   - 剪贴板监控线程
   - 鼠标监听线程
   - GUI 主线程
   - 托盘图标线程
   - 使用标志位和锁避免冲突

3. **时序控制**：
   - 找到最佳的延迟时间组合
   - 平衡响应速度和稳定性

4. **跨应用兼容性**：
   - 适配各种编辑器和输入框
   - 处理不同窗口类名和控件类型

## ✨ 核心功能

- 📋 **自动记录复制历史** - 监控剪贴板变化，自动保存复制历史（最多20条）
- 🖱️ **智能右键触发** - 在输入框中单击右键调出菜单，选中文字时不干扰正常复制
- 💾 **持久化存储** - 历史记录保存到本地，重启后依然可用
- 🎯 **快速粘贴** - 单击选择历史内容即可粘贴到当前位置
- 🎨 **友好界面** - 简洁直观的图形界面，支持鼠标滚轮
- 🔍 **广泛支持** - 支持记事本、VSCode、Word、浏览器等各类软件
- 📦 **便携免安装** - 单个exe文件，可直接运行
- 🚀 **开箱即用** - 无需Python环境，复制到任何Windows电脑即可使用

## 🎮 使用方法

### 启动程序

**使用便携版（推荐）:**
1. 下载 `ClipboardManager_Portable` 文件夹
2. 双击 `ClipboardManager.exe` 或 `启动程序.bat`

**或从源码运行:**
```bash
python clipboard_manager.py
```

### 基本操作

1. **正常复制文本** - 使用 Ctrl+C 或右键复制，内容会自动记录
2. **在输入框中单击右键** - 光标在输入框时，单击鼠标右键调出历史菜单
3. **选择内容** - 单击鼠标左键选择要粘贴的内容
4. **自动粘贴** - 选中的内容会自动粘贴到光标位置

### 智能识别

- ✅ **未选中文字** + 右键 → 弹出粘贴菜单
- ✅ **选中文字** + 右键 → 不弹菜单，允许正常复制
- ✅ **非输入框** + 右键 → 显示系统右键菜单

## ⚙️ 配置说明

程序会在运行目录创建 `clipboard_config.json` 文件,保存历史记录。

你可以修改 `clipboard_manager.py` 中的参数:

```python
manager = ClipboardManager(max_history=20)  # 修改最大历史记录数
```

双击间隔时间调整:
```python
self.double_click_interval = 0.5  # 修改双击间隔时间(秒)
```

## 🔧 技术栈

- **pyperclip** - 剪贴板操作
- **pynput** - 全局鼠标监听和键盘模拟
- **tkinter** - 图形界面

## 📌 注意事项

1. 程序需要在后台持续运行才能监控剪贴板
2. 首次运行需要安装依赖包
3. 只记录文本内容,不支持图片等其他格式
4. 菜单会在失去焦点或按ESC时自动关闭

## 🎯 快捷键

- **双击右键** - 打开历史菜单
- **ESC** - 关闭菜单
- **鼠标点击** - 选择并粘贴
- **Ctrl+C** - 退出程序(在命令行窗口)

## 🐛 常见问题

**Q: 双击右键没有反应?**
A: 确保两次点击间隔在0.5秒内,可以调整 `double_click_interval` 参数

**Q: 粘贴没有反应?**
A: 确保目标位置是可输入的文本框,且光标已聚焦

**Q: 程序崩溃或报错?**
A: 检查是否正确安装了所有依赖包,尝试重新安装 requirements.txt

## 🔨 开发者指南

### 从源码打包成可执行文件

如果你想自己打包程序，按以下步骤操作：

#### 1. 安装打包工具

```bash
pip install -r requirements.txt
```

这会安装包括PyInstaller在内的所有依赖。

#### 2. 打包程序

**方法1: 使用自动脚本（推荐）**
```bash
build.bat
```

这会自动清理、打包并生成 `dist\ClipboardManager.exe`

**方法2: 手动打包**
```bash
pyinstaller clipboard_manager.spec --clean
```

#### 3. 创建便携版发布包

```bash
create_portable.bat
```

这会创建一个完整的 `ClipboardManager_Portable` 文件夹，包含：
- ClipboardManager.exe（主程序）
- 使用说明.txt
- 添加到开机启动.bat
- 取消开机启动.bat
- 启动程序.bat

#### 4. 分发到其他电脑

将 `ClipboardManager_Portable` 整个文件夹复制到其他Windows电脑即可使用，无需任何配置！
